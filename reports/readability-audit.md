# 配色可读性与覆盖检查

2026-10-24 的仓库检查复现了低对比度文字、按钮文字层叠冲突和一个失效的类选择器。修复后的浏览器样本通过全部断言。Steam 的本地 HTTP 调试接口无法连接，因此本次结果不代表真实客户端所有界面已验证。

检查对象是 [manifest](../skin.json) 加载的六份 CSS，覆盖主窗口、库、详情、下载、设置、菜单、好友聊天、商店和列表的现有规则。测量使用仓库的[颜色计算](../scripts/color.mjs)、[筛查规则](../scripts/coverage-rules.mjs)和真实 Chromium 计算样式。

## 验证与边界

使用 Node.js 22.23.2 和 Chrome for Testing 151.0.7922.34，在独立的本地无头浏览器上执行以下命令。共 43 项测试通过，失败和跳过均为 0。

```bash
STEAM_CDP_TEST=1 STEAM_CDP_ENDPOINT=http://127.0.0.1:9224 npm test
```

该命令需要端口 9224 上已有本地 CDP 浏览器。新增样本在 `newonsteam`、`search_page`、`sale_page_background` 和 `v6` 四种页面类中，分别强制普通、悬停、焦点与可见焦点伪类。测试逐项确认样本具有可见文字，再扫描低对比度和疑似深色遗漏。已有测试同时检查素材保色、菜单、设置、下载、详情、商店侧栏和购买区域等样本。

真实 Steam 的导航、滚动区域、好友在线状态组合及所有弹窗仍需逐页采集。图片、渐变、透明层、伪元素、Shadow DOM 和原生窗口的检测限制见[覆盖检查说明](../docs/theme-coverage.md)。本次未修改已安装主题，也未将历史覆盖报告作为当前版本通过的证据。
